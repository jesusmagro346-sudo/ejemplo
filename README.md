# 🚀 Plataforma Web Corporativa - Mi Empresa

Este proyecto es la carta de presentación digital de nuestra organización, diseñado con las mejores prácticas web para ofrecer una experiencia rápida, moderna y segura a nuestros clientes.

## 🎯 Objetivo del Proyecto
El objetivo principal de este repositorio es construir y desplegar la estructura inicial del sitio web corporativo de la empresa. La plataforma está orientada a:
* **Exponer los servicios clave:** Detallar nuestras soluciones en desarrollo de software y ciberseguridad.
* **Presentar métricas de impacto:** Mostrar de forma visual y transparente el crecimiento y rendimiento que ofrecemos a nuestros clientes.
* **Facilitar la conversión:** Proveer tablas de planes tarifarios claras junto con canales de contacto directos.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Para la maquetación semántica y estructura del contenido.
* **SVG Nativo:** Implementado para gráficos ligeros e interactivos de alto rendimiento.
* **Git & GitHub:** Utilizados para el control de versiones y el flujo de trabajo colaborativo mediante ramas (branches) y Pull Requests.
